# solutions —— 参考实现

这里放参考实现，不是让你抄的。

## 使用规则

1. 先自己写：`exercises/dayXX/main.py` 里独立完成当天的练习和实战产出
2. 卡住再看：写不出来（超过 15 分钟）再打开对应文件，只看那一个函数
3. 对比差异：把你没想到的写法抄进 `notes/dayXX.md` 的「今天踩的坑」
4. 不要复制粘贴：代码必须自己敲一遍，否则等于没学
